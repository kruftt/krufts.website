In this article we will trace through some of the ancient steps that can help us to understand some of the wonderous properties of spheres, all without using the tools of modern calculus!

First things first, lets remind ourselves of the intuitive picture of what we mean by length, area, and volume. We say that length is a a measure of a 1D space, an area is a measure of 2D space, and volume is a measure of 3D space:

So long as we stick with lines, rectangles, and rectangular cuboids, measuring these spaces is straightforward. We can imagine using a straight-edged ruler and measuring the length of each side. Then, to get an area or volume, we can simply multiply these lengths together to get the result.

However, things get dramatically more complicated when we start considering curved edges. Before we get going, we need to prepare some geometric tools that will help us deal with this difficulty.
